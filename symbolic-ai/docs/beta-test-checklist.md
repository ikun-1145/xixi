# Sunland AI v0.1.0 Beta 测试 Checklist

本清单面向小规模封闭测试。每个测试者使用独立测试账号，不输入真实隐私、支付或其他
敏感内容。Diagnostics 只在测试者明确理解并同意后开启。

## 0. Launch Gate

- [ ] 已复核生产 `conversations` 和相关用户数据的服务端访问控制，确认无法跨用户读写。
- [ ] 已指定测试负责人、问题响应人、停止测试负责人和反馈接收渠道。
- [ ] 已告知测试者这是 Beta、可能出错、不要输入敏感内容，以及如何退出测试。
- [ ] 已准备两个以上相互隔离的测试账号，用于交叉验证。

任一 Launch Gate 未完成，不邀请真实用户进入。

## 1. 发布完整性

- [ ] `npm run test:api-surface` 通过，v0.1.0 仍为 70 个运行时导出。
- [ ] `npm run release:core` 与 `npm run check:core-release` 通过。
- [ ] Web/Flutter Bundle SHA256 与 release report 一致。
- [ ] Web、Flutter 和 Core 全量测试通过。
- [ ] 已审核 Flutter 静态分析基线；当前 75 项既有 lint 均已记录责任人与处置计划。
- [ ] Provider、认证、会话格式和 SDK API Surface 没有未审核变更。

## 2. Web 首次体验

- [ ] 无 Token 访问 `ai.html` 会进入登录页，不出现空白或闪烁的聊天页。
- [ ] 空邮箱提示“请输入邮箱”；错误邮箱提示“邮箱格式错误”。
- [ ] 协议与隐私政策链接可打开，未同意时不能登录。
- [ ] 测试验证码登录成功后自动进入聊天页并出现一个可用的新对话。
- [ ] 测试者能独立找到模型菜单并选择 `Sunland AI · Beta`。
- [ ] 测试者能复述：Sunland 是本地符号推理，当前不支持文件上传和深度思考。
- [ ] 发送第一条消息后 Provider 锁定；尝试切换时明确要求新建对话。

## 3. Flutter 首次体验

- [ ] 登录页产品说明、协议与隐私入口可见。
- [ ] 无消息时显示欢迎语和三个快捷入口，不发生布局溢出。
- [ ] 模型选择中能看到 `Sunland AI · Beta` 和“本地符号推理，不使用 DeepSeek”。
- [ ] 选择 Sunland 后文件上传、深度思考禁用，发送第一条消息后 Provider 锁定。
- [ ] 新建对话后可以重新选择 Provider。

## 4. Knowledge / Memory

在 Sunland 会话按顺序执行：

- [ ] 发送“我叫什么”，回复说明目前不知道并邀请提供名字。
- [ ] 发送“我叫小蓝”，再发送“我叫什么”，回复包含“小蓝”。
- [ ] 发送“星尘兽会唱歌”，回复明确表示已记录。
- [ ] 发送“星尘兽会什么”，回复包含“唱歌”。
- [ ] 新建 Sunland 对话后仍能回忆姓名和教学知识。
- [ ] 同账号 Web/Flutter 恢复相同会话时，消息和卡片格式没有损坏。
- [ ] 切换到另一个测试账号后看不到前一个账号的姓名、知识或会话。
- [ ] 设置页能区分姓名 Memory 和用户教学 Knowledge。
- [ ] 删除一条教学知识只影响该条；清除全部不影响内置知识、Memory 或聊天记录。
- [ ] 清除姓名不影响教学知识或聊天记录。

## 5. 错误与空状态

- [ ] 无教学知识时显示明确空状态，不显示空白列表。
- [ ] 无 Diagnostics 数据时显示“暂无本地诊断数据”。
- [ ] 断网、超时、429 和 5xx 在测试环境中分别显示可恢复提示；不得为测试故意攻击生产服务。
- [ ] 临时网络错误不会直接清除有效登录态。
- [ ] 身份无效时要求重新登录，不继续读取旧账户数据。
- [ ] Sunland 本地错误显示稍后重试，不暴露 stack、Reasoner 或 Semantic 内部诊断。
- [ ] 删除会话失败时原会话仍可恢复，不出现假删除。

## 6. Beta Diagnostics（仅 Web）

- [ ] 初始为收起和关闭状态，未开启前不创建 Diagnostics 数据边界。
- [ ] 测试者能复述：仅本机保存、不会自动上传、不包含对话/姓名/教学知识/账号标识。
- [ ] 开启前出现确认；取消确认不会启用。
- [ ] 开启后只有后续完成的 Sunland 请求计数，DeepSeek 请求不计数。
- [ ] 测试者知道 `Context/Legacy/副作用/安全降级` 是内部聚合分类，而不是用户评分。
- [ ] 查看、复制和导出的摘要内容一致且不含身份或自由文本。
- [ ] 关闭后明确提示已有数据仍保留；单独清除后数据消失。
- [ ] 仅在测试者主动选择后，通过约定渠道提交导出文件。

## 7. 可访问性与设备覆盖

- [ ] Web 桌面与移动端均可完成登录、模型选择、发送、停止和新建对话。
- [ ] 键盘可访问登录字段、协议、模型选择、Diagnostics 和数据管理按钮。
- [ ] 屏幕阅读器能读出输入标签、按钮用途、Diagnostics 状态和错误提示。
- [ ] Flutter 至少覆盖一台 Android 和一台 iOS 真机。
- [ ] 弱网、前后台切换、刷新和应用重启后不会串会话或重复发送。

## 8. 停止条件

出现以下任一情况立即停止测试并保留日志：

- [ ] 任意跨账号数据可见或可修改。
- [ ] Provider 在已开始会话中被静默更换。
- [ ] Web/Flutter Bundle hash 或 manifest 不一致。
- [ ] SDK API Surface 契约失败。
- [ ] 删除操作影响其他账号、内置知识或非目标数据。
- [ ] Diagnostics 出现对话文本、姓名、教学知识、账号标识或自动上传。
- [ ] 登录/刷新循环导致无法退出或持续丢失会话。

## 9. 测试记录

每位测试者至少记录：

- 平台、浏览器/系统版本和测试时间；
- 完成与失败的 checklist 项；
- 首次找到 Sunland、完成第一次教学和理解 Diagnostics 所需时间；
- 错误提示是否知道下一步；
- 问题复现步骤、期望、实际结果和匿名截图；
- 是否主动导出 Diagnostics，以及提交前是否确认内容。
