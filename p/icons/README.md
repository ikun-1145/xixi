# UI icons

The SVG files in this directory come from [Lucide](https://github.com/lucide-icons/lucide) at commit `c967b3225c7709bfa9457cfa446a46ee19521d63`.

Lucide was selected after Worldvectorlogo searches returned brand logos rather than generic UI symbols. The icons are stored locally so the static site has no icon CDN or JavaScript runtime dependency. See `LICENSE` in this directory for the upstream ISC/MIT license text.
